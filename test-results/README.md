# Test Results | Resultados de Pruebas

## English

### Overview

This section documents the execution results of the Urban Scooter QA training project, including web application testing, input validation, Android mobile testing, and REST API testing.

### Test Execution Summary

| Testing activity | Passed | Failed | Total |
|---|---:|---:|---:|
| Web functional checklist (Chrome and Opera) | 54 | 18 | 72 |
| Input data validation | 28 | 5 | 33 |
| Android mobile test cases | 31 | 15 | 46 |
| REST API checklist | 133 | 40 | 173 |
| **Total** | **246** | **78** | **324** |

**Overall pass rate: 75.9%**

**Overall failure rate: 24.1%**

These figures represent recorded test outcomes. A single defect may affect multiple test checks.

### Defect Traceability

Failed checks are linked to Jira defect reports where references were recorded.

The workbook contains references to 37 distinct Jira issue IDs. One failed API checklist entry has no Jira link recorded.

### Test Execution Evidence

[View Test Execution Workbook](https://github.com/zachecroacia-cyber/urban-scooter-qa-testing/blob/main/test-design/Urban_Scooter_Test_Design.xlsx)

### Conclusion

The execution records demonstrate functional testing across web, mobile, input validation, and API scenarios. The results identify both successful checks and deviations from expected behavior, supported by defect references and test documentation.

## Español

### Descripción

Esta sección documenta los resultados de ejecución de pruebas del proyecto de formación QA Urban Scooter, incluyendo pruebas web, validación de datos, pruebas móviles Android y pruebas de API REST.

### Resumen de ejecución

| Actividad | Aprobado | No aprobado | Total |
|---|---:|---:|---:|
| Lista de comprobación web (Chrome y Opera) | 54 | 18 | 72 |
| Validación de datos | 28 | 5 | 33 |
| Casos de prueba móviles Android | 31 | 15 | 46 |
| Lista de comprobación API REST | 133 | 40 | 173 |
| **Total** | **246** | **78** | **324** |

**Porcentaje de aprobación: 75,9 %**

**Porcentaje de no aprobación: 24,1 %**

Estas cifras corresponden a resultados de comprobaciones registradas. Un mismo defecto puede afectar varias comprobaciones.

### Trazabilidad de defectos

Las comprobaciones fallidas incluyen enlaces a informes de Jira cuando fueron registrados.

El archivo contiene referencias a 37 identificadores distintos de Jira. Una comprobación fallida de API no tiene un enlace registrado.

### Evidencia de ejecución

[Consultar archivo de pruebas](https://github.com/zachecroacia-cyber/urban-scooter-qa-testing/blob/main/test-design/Urban_Scooter_Test_Design.xlsx)

### Conclusión

Los registros evidencian la ejecución de pruebas funcionales web, móviles, de validación de datos y de API. Los resultados permiten identificar tanto las comprobaciones satisfactorias como las desviaciones respecto al comportamiento esperado, respaldadas por documentación y referencias a defectos.
